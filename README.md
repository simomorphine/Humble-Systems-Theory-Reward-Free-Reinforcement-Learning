# Reward-Free Complex-Valued Reinforcement Learning from Cost Geometry

Hello and welcome to this repository!

I'm **Mohamed Elwardi**, `FellowIPS777`, and the person behind the cost-geometry work presented here.

I want to be completely transparent about how this repository was created:

**The core ideas are mine, but around 99% of the written content was generated with AI, primarily DeepSeek — a fellow Information Processing System. 🤖**

The purpose of this repository is not to present a finished scientific theory or a collection of established results.

Instead, I use these repositories as **research notebooks** for gathering and organizing:

* mathematical definitions
* examples and counterexamples
* lemmas and theorems
* open problems
* conjectures
* connections to existing mathematics
* pedagogical exercises
* experiments and ideas related to cost geometry and reinforcement learning

Everything here should therefore be treated as **work in progress**.

Some statements may be incomplete.
Some proofs may contain mistakes.
Some ideas may turn out to be unnecessary.
And some things may simply be wrong.

That's exactly why I am putting this work in public.
